PET ADOPTION PLATFORM - FRESH FOLDER

RUN:
1. Extract the ZIP.
2. Open the extracted PetAdoptionPlatform_Fresh folder in VS Code.
3. Open src/Main.java.
4. Click Run.
5. Open http://localhost:8080 in your browser.
6. To stop the server, click the VS Code Terminal and press Ctrl+C.

MAIN ENTRY:
src/Main.java

This version intentionally keeps Main.java as the simple entry point.
No separate Tomcat installation is required for this first stage.

Next stages will add MySQL/JDBC and the Servlet functionality while keeping
Main.java as the file you run.
